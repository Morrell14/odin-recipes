# Odin Recipes

A small HTML recipe website created while learning with The Odin Project. The home page links to three pasta recipes: spaghetti Bolognese, queso pasta, and carbonara.

**Stack:** HTML.

## View locally

Open `index.html` in a browser and choose a recipe. No dependencies or build step are required.

## Structure

- `index.html`: recipe index.
- `recipes/`: individual recipe pages.
